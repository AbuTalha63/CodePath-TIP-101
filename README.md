# CodePath TIP101: Intro to Technical Interview Prep

My practice work for **CodePath's Technical Interview Prep 101** (Section 3, Fall 2026). I use this repo to work through the course problems, build up data structures and algorithms (DSA) problem-solving skills, and get ready for technical interviews.

## About the Course

TIP101 is a 10-unit course that builds the problem-solving basics you need for technical interviews, using Python coding challenges. Each unit has algorithm lectures, small-group coding practice, and a HackerRank assessment. Along the way there are also mock interviews to practice explaining solutions out loud.

## Approach: UMPIRE

Every problem here is worked through with the **UMPIRE** method:

| Step | What it means |
|------|---------------|
| **U**nderstand | Restate the problem, ask clarifying questions, and walk through test cases and edge cases |
| **M**atch | Spot which known pattern or data structure fits the problem |
| **P**lan | Write out the approach in pseudocode before coding |
| **I**mplement | Turn the plan into working Python |
| **R**eview | Trace through the code with test cases to catch bugs |
| **E**valuate | Analyze time and space complexity (Big O) and look at trade-offs |
